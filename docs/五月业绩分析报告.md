# 贺报

热烈祝贺 天津、新疆达成5月标保目标

# 标保

- 截至5月31日，全系统5月标保共达成12444万，达成率 61.8% ，同比负增 11.6% ，全年达成100538万，全年进度 53.8% ，全年标保同比正增 20.6% 。
- 9家机构5月标保达成率高于 70% ：河南、天津、潍坊、云南、新疆、海南、内蒙古、宁波、甘肃；其中天津、新疆达成5月标保目标；8家机构5月标保达成率低于 50% ：上海、安徽、山西、北京、贵州、青岛、宁夏、深圳；其中深圳达成率不足 5%；
- 7家机构全年标保进度达成高于 60% ：天津、潍坊、云南、新疆、宁波、甘肃、贵州；其中宁波达成进度超 80% ；6家机构全年标保进度达成低于 45% ：安徽、北京、海南、青岛、宁夏、深圳。

# 价值

* 截止5月31日，5月价值达成7045万，价值达成率 74.1% ，同比正增 9.8% ，全年进度 54.2% ，全年价值达成同比正增 7.2% ；
* 5家机构5月价值达成率高于 85% ：河南、天津、云南、吉林、新疆；8家机构5月价值达成率低于 55% ：上海、山西、北京、宁波、贵州、青岛、宁夏、深圳。

# 活动人力

* 截至5月31日，全系统5月活动人力共5531人，达成率 77.9% ，同比负增 9.4% ；
* 6家机构活动人力达成率高于 90% ：重庆、陕西、吉林、潍坊、宁波、新疆；其中宁波达成5月活动人力目标；6家机构活动人力达成率低于 60% ：上海、安徽、北京、内蒙古、贵州、深圳。

# 阳光人力

- 截至5月31日，阳光人力共达成4772人，达成率 82.2% ，同比负增 2.1% ，阳光占比活动 85.2% ；
- 8家机构阳光人力达成率高于 90% ：重庆、河南、陕西、吉林、潍坊、湖南、宁波、新疆；7家机构阳光人力达成率低于 70% ：上海、黑龙江、安徽、北京、内蒙古、贵州、深圳。

# 主管活动

* 截至5月31日，全系统在职主管共3484人，主管活动2485人，活动率 71.3% ，活动率同比负增1.1pt；
* 5家机构主管活动率高于 80% ：重庆、浙江、江苏、潍坊、深圳；6家机构主管活动率低于 60% ：广东、上海、陕西、山西、宁夏、青岛；

# 主管双星

* 截至5月31日，主管双星共达成1300人，双星达成率 37.3% ，达成率同比负增4.3pt。
* 6家机构主管双星率高于 50% ：浙江、江苏、福建、潍坊、深圳、海南；6家机构主管双星率低于 25% ：陕西、山西、贵州、甘肃、宁夏、青岛。

# 标准组

- 11家机构标准组同比负增超过 20% ：广东、上海、安徽、黑龙江、北京、山西、深圳、海南、内蒙古、贵州、宁波；16家机构标准组占比低于 30% 的机构：山东、广东、上海、安徽、黑龙江、北京、陕西、山西、深圳、海南、新疆、贵州、甘肃、宁波、宁夏、青岛。

# 新增

- 截至5月31日，全系统送训1510人，新增739人，目标达成率 62.6% ，同比负增 7.4% ，起聘首阳人数425人，首阳率 45.6% ；大专+学历人力占比 47.5% ，同比正增16.3pt，本科+学历人力占比 25.4% ，超额5.4pt；
- 4家机构新增达成率超过 80% ：河北、河南、山西、青岛；2家机构达成5月新增目标：宁波、深圳；
- 9家机构新增达成率低于 40% ：广东、吉林、天津、黑龙江、北京、新疆、宁夏、贵州、海南；
- 21家机构达成本科占比目标，其中8家机构超额10pt：江苏、福建、上海、四川、陕西、深圳、甘肃、内蒙古；
- 10家机构未达成新增本科占比目标：河南、浙江、重庆、广东、天津、宁波、青岛、宁夏、贵州、海南。

# 同引

- 截至5月31日，全系统5月送训111人，同比负增 14% ；二季度上岗105人，达成率 38.2% ，同比正增 47.9% ；二季度同引主管大专+学历人力占比 41% ，同比正增0.1pt，本科+学历人力占比 16.2% ，同比正增0.7pt；

- 2家机构达成二季度同引目标：河南、青岛；

- 3家机构达成率超过 50% ：江苏、陕西、甘肃；

- 7家机构二季度同引挂0且5月送训挂0：重庆、福建、天津、贵州、宁波、海南、深圳。
